# Stödassistenten – Pilot

Mobil pilot för att testa hypotesen: kan en person beskriva sin situation och få begripliga, källspårbara vägar till stöd utan att först känna till myndighetsspråk eller stödsystem?

## Pilot V0.3

- Svenska, arabiska och persiska
- Tre testscenarier: pensionär, familj med autism/NPF, förening/litet företag
- Officiella källänkar per stöd
- Inbyggd anonym pilotfeedback: relevant / kände redan till / inte relevant
- Feedback delas från användarens egen enhet via systemets delningsmeny
- Ingen central lagring av hälsa, ekonomi eller personuppgifter i denna fas

## Pilotprinciper

1. Appen säger inte att användaren har rätt till ett stöd – bara att det är relevant att kontrollera.
2. Villkor verifieras mot originalkällor.
3. Samla minsta möjliga mängd data under tidig pilot.
4. Bygg vidare mot regelmotor + AI-intervju efter att UX och behov validerats.

## Nästa steg

- Pilot med 5–10 personer
- Mäta relevans, nyupptäckta stöd och begriplighet
- Utöka stöddatasetet
- Separera språk/data/UI i moduler
- Koppla riktig backend och AI-intervju
- Dokumentfoto och ärendehantering först efter integritetsdesign
